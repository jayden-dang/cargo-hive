# ADR-0002: Plans of every class apply with no human step

Hive was going to stop plans for protected checkouts and orphan targets at `needs-human` until the owner approved them with Touch ID or a password through `cargo hive approve` (ROAD-7, ARCH-12). The owner dropped that on 2026-11-02, before it shipped: a deletion from a target dir holds no sensitive data, an agent can already delete a target by hand (the vision already refuses to claim main is protected from agents), and what keeps a build sound is the lock (ARCH-19) and the apply-time recheck (ARCH-20), which every class still goes through. Accepted cost: a unit collected from main rebuilds when a command next needs it, a receipt reports the deletion only afterwards, and an orphan removal takes anything in that target no build recreates, such as `target/criterion` baselines, including for a repo that was never registered. Revisit by adding a condition to orphan plans if that last case causes real loss, before bringing back a human step.
